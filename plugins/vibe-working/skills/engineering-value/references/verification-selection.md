# 验证形态选择

一个测试值得写的条件：它能发现一种具体失败，那种失败逃逸的代价高于写它、跑它、维护它的成本，且现有检查没有覆盖。本文把这条原则展开成可直接执行的规则。Claude 以本文为参考自主判断；Codex 按本文执行，本文没覆盖的情形按"失败形态、逃逸代价、已有覆盖"三问决定，并把决定写进执行报告。

## 一、任何任务都适用

- 交付前运行方案里的验收命令，以及 `CONSTRAINTS.md` 中标为"每次交付"的检查。
- 新写测试的范围上限是本次改动或新增的函数与分支。不给未改动的代码补测试，除非方案要求，或属于第二节的重构场景。
- 每个测试对应一个能写出来的失败形态。写不出"输入 X 时本应 Y、错误实现会 Z"的测试不写。
- 不写这几类：断言 mock 被调用的次数或顺序；对整个对象或页面做快照；测试框架、标准库或供应商 SDK 的行为；同一分支已在单元层覆盖，再在集成层重复。
- 只 mock 外部系统（第三方 API、模型服务、时钟、随机源），不 mock 本仓库的模块；需要隔离本仓库模块时用真实实现加内存存储。

## 二、按任务类型

| 任务 | 必写 | 不写 | 验收信号 |
|---|---|---|---|
| 新功能 | 每条验收标准至少一个用例；改动函数的正常路径、每个边界、每条错误路径各一个用例 | 变异测试（留给闸门）；性能测试，除非需求给了指标 | 新用例通过；仓库原有测试全过 |
| debug | 先用出问题的真实输入写一个失败的复现用例，修复后转绿；再写一个表面相似但不该触发修复逻辑的合法输入，确认原行为保留；原因在集成层（鉴权、路由、代理、数据库）时，复现用例走真实路径 | 为所在模块补全套测试；修复范围以外的用例 | 复现用例修前红、修后绿；邻居用例始终绿 |
| 重构（行为不变） | 现有测试是判据。改动函数的覆盖率低于 `CONSTRAINTS.md` 阈值时，改之前先写特征测试：取代表性输入记录当前输出，改完对比 | 新验收用例；改写现有断言的期望值 | 现有测试与特征测试全过，期望值一字未改 |

## 三、按失败逃逸代价

先给改动涉及的每个函数定档，档位决定测试深度：

| 档 | 范围 | 要求 |
|---|---|---|
| T1 | 权限与鉴权、资金与计费、持久化写入、数据迁移、并发状态 | 负向用例必写：无权限、重复提交、越界值、并发重入；每个分支都有断言；改动行覆盖率 100% |
| T2 | 业务逻辑、计算、流程编排 | 正常路径、边界、错误路径各一 |
| T3 | 日志、展示、格式化、文案 | 一个快照或不测；改动行覆盖率不作要求，在报告里注明 |

一个函数同时落多档时按最高档。

## 四、按功能类型选形态

| 功能类型 | 用这种形态 | 这种形态低价值 |
|---|---|---|
| 算法、纯计算 | 表驱动的边界用例；有不变量时写性质测试（任意输入下不变量成立） | 只测一个正常输入 |
| 状态机、流程 | 转移表逐条用例；每个终态可达；非法转移被拒绝 | 只测主路径 |
| 校验与解析 | 合法输入、非法输入、边界值各一组；非法输入断言错误类别，不只断言"抛错" | 断言错误消息全文 |
| 异步、队列、重试 | 重复投递幂等；乱序到达；超时后的重试与终态；终态能从持久状态回读 | 用 sleep 等待的时序断言 |
| 外部依赖适配 | 用录制的响应测自己的解析与错误分类（限流、额度、审核拒绝、超时分开） | 对真实外部服务跑单元测试 |
| IO、胶水、配置装载 | 一个冒烟用例走通即可 | 用 mock 把胶水测成单元 |
| 展示、格式化 | 快照 | 逐字段断言 |

## 五、按架构边界放测试

| 架构 | 放置 |
|---|---|
| 库、纯函数模块 | 单元测试为主 |
| 分层服务（API → 领域 → 存储） | 领域逻辑单元测试；每个边界一组契约用例（请求响应 schema、存储接口）；经过真实鉴权、代理、数据库的集成路径至少一条 |
| 事件驱动 | 第四节"异步"一行，外加消费者各自的幂等用例 |
| 前端、可视化 | 逻辑用组件测试；观感用截图对比，自动比对不了的标 `MANUAL` 写人工步骤 |
| 数据管道、模型 | 输入输出 schema 与不变量检查；小固定输入的黄金输出；随机过程用配对随机种子比较，断言设统计容差 |

改动触及鉴权、路由、代理、数据库或外部契约时，必须有一条真实路径的集成用例；本地跑不了的（需要生产凭据、付费接口）标 `MANUAL`，写明手工步骤与期望，不用恒真断言占位。

## 六、超出预算时的收缩

方案给了时间预算或测试耗时明显超过实现本身时，按 T1 → T2 → T3 收缩，T1 不收缩；被跳过的函数与原因写进执行报告。测试因环境原因跑不起来时记为阻塞，不改成跳过。
