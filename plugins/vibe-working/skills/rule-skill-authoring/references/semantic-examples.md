# 语义规则的案例方法

本文件用于为目标 skill 提炼、选取、修订或评估运行案例；案例来源要求由 [SKILL.md](../SKILL.md#语义规则的案例辅助) 维护。案例补充抽象规则未充分表达的判别信息，规则正文继续拥有权威、适用域和验收定义。

## 找到案例要补充的信息

当多个行为都符合规则字面要求，却在意图、语境、功能、因果作用、审美或专业效果上不同，定位人类评审能够解释的决定性差异。有迹象表明失误来自加载、事实、权威或执行能力时，先处理对应原因。高后果提高依据与验证要求，本身不决定是否加载案例。

根据缺口选择案例，不固定数量或组合：

| 类型 | 提供的判别信息 |
|---|---|
| 正例 | 展示一种合格实现，以及使其合格的机制 |
| 近边界负例 | 展示表面合理但越过规则边界的行为及原因 |
| 非触发例 | 说明表面相似时，适用条件为何不成立 |
| 修复对 | 指出哪项变化使行为重新合格，保留判断所需上下文；修正版取自实际采纳的修订 |

用户或领域专家反馈的实例先关联到它说明的具体规则，保留裁决范围和理由。具有判别信息、适用于当前任务且已有使用授权时，可以直接选作 few-shot；声望、商业成绩、benchmark 标签或情绪不能单独决定合格性。负例保留归因所需上下文和修正方向。用户在其权威范围内的明确要求即时生效；跨任务复用还需机制与迁移依据。

## 记录与归属

保留理解案例与判别所需的上下文、片段和理由；共同的来源、裁决依据与适用范围可以一起说明。开发分析、运行提示与独立评测的用途应可区分，沿用足以表达的现有材料。

去掉专名与表面形式后，检查机制是否仍可解释同类任务，以及为何排除相邻合法任务。运行示例展示一种成立方式；避免把偶然措辞、段落结构或步骤复制成唯一合格答案。

实际案例归目标 skill 所有，放在其执行者可按条件读取的位置。案例与本次语义决策相关时加载，来源或裁决变更后更新。多消费者与重复维护问题已出现，且共享机制有明确行为收益时，再评估共享库、schema 或检索。

用户工件、版权材料、商业秘密与敏感数据按其授权范围使用。请求修订本次任务不自动授权持久化到共享示例库；已有授权足够时直接执行。

## 使用判断与效果验证

案例的正常使用依据其判别信息、适用范围和授权，专业判断或实际使用足以支持选取时即可采用。尚未做增益比较的案例保留其来源与使用依据，不据此声称稳定改善。已有结果显示无增益或退化时，结合观察条件调整选取、修订案例或移出运行提示。必要的权威规则不能因一次模型实验未改善就被撤销。

扩大案例复用范围时，检查机制及判别信息是否仍适用；关键迁移条件难以判断或失效后果较大时，再选代表性任务检查。需要宣称效果提升时，取得与该主张相称的行为证据，已有适用证据可以复用。比较案例增益时，使用模型、工具与任务条件可比的规则文本基线和案例增强版本，说明未受控差异。检查目标遵循、整体质量、误触发、过度约束、表面复制与上下文成本。未展示任务应改变表面形式和上下文，并覆盖会改变裁决的边界。

运行提示与最终留出评测保持分离；曾用于调试、挑选案例或改规则的任务属于开发材料。开发期可重复使用它们作回归，但不能再充当独立泛化证据。

模型自身评语只提供复核线索。验收使用实际决策和产物；人类判别尚有争议时保留争议范围，明确需谁裁决。验证深度随风险、部署范围和拟作主张决定；小规模试用不需要宣称跨领域有效。

未观察到增益时据此调整使用判断；需要复用或对外主张效果时再保存对应条件与结果。观察到退化时定位是否来自错误案例、加载时机、规则冲突或表面模仿，修改对应原因；有持续回归价值的材料再保留。
