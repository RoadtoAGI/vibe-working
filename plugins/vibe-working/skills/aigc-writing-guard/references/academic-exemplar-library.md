# 论文参考消费

需要具体论文示范来解决表达问题时使用本页。普通生成、润色和语义审阅使用共通规则即可。已有片段及其分析足以指导当前改动时，直接复用。

## 取得适用参考

按当前已有材料选择入口：

- **已读片段或用户提供的原文**：利用片段及必要上下文，辨明其句段功能、信息顺序和术语关系。局部表达任务可以直接使用，不要求先登记论文或制作参考包。
- **已有表达参考包**：读取 `selection_scope: expression` 对应的 `style_synthesis_file`，并沿选中卡片或综合材料中的来源定位取得原文。参考包沿用 `academic-exemplar-pack/v1` 的状态与作用域；未声明 `selection_scope` 的旧包继续遵循其旧契约，不能自动当作完成的表达包。
- **项目论文库**：库根以项目约定或用户提供的位置为准；默认库为当前加载的 `academic-exemplar-analysis` 技能目录内的 `library/`。该相对库根按所属技能目录解析；`library.json` 内的 `analysis_file` 和 `source.local_file` 按该目录解析，参考包内的路径按包目录解析。按当前写作问题检索目录，读取分析卡及原文定位。

需要新选取参考、补充拆解或更新库时，在当前环境可用的情况下加载 `academic-exemplar-analysis`，表达任务使用其 `expression` 范围。该 skill 维护库、分析卡和参考包的完整契约；本 skill 消费表达示范。依赖或参考不可用时继续已有材料支持的工作，只有依赖该参考的交付才说明具体缺口。普通文风修订无需新建这些产物；新增参考或交接材料按当前任务需要与授权处理。

## 沿用来源与状态

现有库以 `academic-exemplar-library/v1` 的 `library.json` 和分析卡为权威。目录字段用于检索和定位：

| 信息 | 消费方式 |
|---|---|
| `library_id`、`analysis_file`、`source_anchors` | 找到分析卡及源文件、页码或章节，标签不能替代实际片段 |
| `analysis_status` | 优先使用 `complete` 卡的相关分析；局部或旧卡材料只在已读取、定位和确认的范围内使用，保留原状态 |
| `experimental_design_status` | 与表达分析分开维护；实验层 `open` 或 `legacy_unreviewed` 不自动否定已确认的表达机制，也不授权实验设计迁移 |
| 包的 `status` 与 `selection_scope` | 完成状态只覆盖声明范围；表达参考包的完成不代表实验设计完成 |

目录中有来源路径或卡片标记完成，只能帮助找到材料。采用某项表达机制时，读取对应原文及足以理解其作用的上下文；已经读过且仍适用的内容直接复用。来源不可读时不虚构示范，也不升级卡片或包状态。

## 用于当前文本

先看示范是否解决当前句段的信息组织、对象指代、术语解释或衔接问题，再结合语言、学科和体裁判断迁移方式。跨语言参考保留信息关系，使用自然的目标语言重写；venue 和主题只帮助筛选。

迁移原文的表达机制和成立条件。来源论文的事实、数值、研究结论、作者限定与特色措辞仍属于来源；目标正文遵循 [共同约束](../SKILL.md#共同约束) 和项目作者权限。参考使用不会自行启动目标论文的论证效力审查。

直接交付当前任务需要的正文或表达发现。需要解释选择或交接时，在已有工作记录中保留 `library_id + 原文定位` 或片段来源，不另设逐段登记。检查实际修订是否解决表达问题，库和参考包的结构状态不代替成文判断。
