# Prompt 契约

以下 prompt 是各任务入口的可复制摘要，按需选用。共同目标是在原意和任务约束内选择更清楚、准确、自然的表述。任务范围、内容保护及补充材料的加载条件遵循 [技能入口](../SKILL.md)，诊断条件见 [高级语义模式](semantic-families.md)，语言专属词项与真实改稿对见 [中文判据](zh-wording.md) 与 [英文判据](en-wording.md)。已加载时直接复用，无需依次运行全部 prompt；分组用于选择诊断，不规定文章结构。

## 生成前防治 prompt

```text
你正在撰写[文档类型]的[章节或交付物]。

写作目标：[目标]
读者与决策场景：[受众]
可用事实、数据和来源：[材料]
受保护内容：[事实、数字、公式、引用、专名、必要限定、用户结论]
输出格式与目标语言：[格式、语言]

遵守受保护内容、任务范围和格式要求。整篇或整节任务包含正文与各级标题，检查重点随实际阅读问题确定。保持作者原有结论力度与限定，新增内容依据材料；输入不足时保留原状态，必要时在工作记录说明。稿件内容和位置遵循项目作者权限。

阅读与信息：表达可以提供事实，也可以承担回指、承接、解释准备、导航、定义、引用归属和条件说明。保留必要主语、宾语、比较对象与单位；按理解依赖介绍概念和关系。删除没有内容功能的自我标注及成稿任务话语，保留有效的重复、指代和连接词。

语义指向：评价落到对象、动作或具体关系，“清晰、有效、robust”这类评价词能回答“相对什么”，答不出就写具体属性或删去；来源指代清楚；比喻准确对应机制。保留已经定义的术语和准确压缩，按已有材料补明含义。

论证姿态：不为衬托结论否定一个无人主张的选项（不是 X 而是 Y、not X but Y），不虚设“有人认为、Many believe”的对手；被否定或反驳的看法在材料里有归属时保留并写明，没有就直接陈述结论及其条件。

文体组织：按实际内容组织条目和篇幅，直接写核心判断及成立条件，连接词标记真实逻辑变化。并列“X 与 Y”只在各项有内容或并列本身就是信息时使用，正文已建立关系或结论的，标题和句子写出关系而不是罗列。标题结合所辖内容及父级、同级语境准确提示主题与范围，形式按用途选择。用目标体裁的语域：讲义、说明和随笔不用半公文书面腔（尚未、亦、予以、进行、serves as、utilize 成片）；日常、医学、学术或商业正文避免套用代码设计、验证报告或 agent 执行记录的闸门、状态、版本和分支结构。字面技术用法保留；可行方案写清各自条件，删除模型自设的排他性宣言。

按目标语言读取对应判据页并选择表层词库，检查自然搭配；中英文命中与密度均只帮助复核。具体挑战及解法、定义公式的冒号和必要方法对照按其功能保留。学术定位、主张与结果解释沿academic-writing作者权限处理，检测命中不授权删除或弱化。复读相连句段，确认对象和解释顺序可追踪。清楚自然的表达可以保持，改写须有具体阅读收益。

输出正文，不附执行过程、自我评价或 AI 风险分数。
```

## 语义审阅 prompt

```text
审阅下列非创意文本的表达功能。整篇或整节任务包含正文与各级标题，局部任务按指定范围审阅，检查重点随实际阅读问题确定。本轮只诊断，保持事实、数字、公式、引用、专名、必要限定及作者结论强度，不改写正文。

共同约束：有原文或作者材料可比较时，检查明确结论是否被擅自降为猜测或添加自我限定；按 unrequested_claim_weakening 指出具体改动。论证效力审查按项目任务边界启用。

阅读范围包含必要的前后文，判断回指、句段承接、解释准备、比较结构和导航。重复或连接没有新增事实，也可能降低理解负担。有旧稿时区分已有缺口与本轮新增退化；缺少旧稿时只描述当前问题。表层库按目标语言选取，词密度不决定语义严重度。英文定位候选先辨明比较双方和段落职责，按academic-writing作者规则交接；第三方背景比较和方法定义所需对照可以保留。

按文本问题选择诊断：
- 信息冗余：按局部功能判断表演式前缀、无信息作用的命题表演、语义复读和其他可压缩表达。表演式前缀及任务话语候选须确认属于无功能自我标注或成稿执行话语后报告；其他冗余按其功能问题报告。必要承接、通俗重述、导航、引用对象和法规限定按实际用途保留。
- 语义指向：抽象评价是否遮蔽具体关系，来源指代是否明确，比喻映射是否成立。指代已在上下文明确或术语已定义时保留，不补造内容。
- 论证姿态：被否定的选项或被反驳的看法在文中有归属吗？找得到的保留并核对内容完整；找不到的报告为否定转折骨架或虚设对手，修订方向是直接陈述结论及条件。精确逻辑区分、程序性两分和作者核实过的读者误解不报告。
- 文体组织：正文模板是否压过真实关系；并列“X 与 Y”是罗列项目还是说出了关系；标题能否结合父标题、同级目录和正文区分各节；书面腔虚词是否成片且与体裁不符；非代码文章是否套用代码文档语域。语域候选既无字面技术对象，也无正式机制，且可无损还原为领域事实、条件和后果时，报告跨域污染。仅有标题时，建议限于已知内容。

阅读实际文本，lint 命中仅用于定位。同一功能问题按决定修订动作的具体模式报告一次：表演式前缀用 performative_preface，任务话语泄漏用 meta_performance，否定衬托用 contrastive_scaffold，虚设对手用 strawman_opening，正文并列用 hollow_coordination，标题导航问题用 formulaic_heading，书面腔用 stiff_register，代码文档语域错位用 code_document_register_leakage；上位原则只解释原因，其余冗余可用 low_information_density。无法指出功能问题的候选保留为观察。

用原文位置或短引、功能问题和修订方向说明发现；分类、violated_principles 或覆盖状态按消费者需要提供。未执行的检查不声称完成，不判断作者身份或 AI 概率。

待审文本：
[TEXT]
```

## 语义修订 prompt

```text
在允许范围内润色下列文本，或修复指定 findings；按用户实际任务选择。

受保护内容：[事实、数字、公式、引用、专名、必要限定、用户确认结论]
允许修改范围：[span 或章节]
findings：[已有审阅结果，没有则省略]

遵守受保护内容和原有格式，保持作者结论力度。发现无请求的结论降级时恢复原意，保留原文已有的限定。材料不足处保留原状态，必要时在工作记录说明；新增稿件说明服从作者权限。

整篇或整节润色覆盖正文与各级标题，已有 findings 帮助定位，检查重点随实际阅读问题确定。只修指定问题时，处理对应表达与受影响的衔接，周边内容提供语境。

按实际问题选择修法：
- 信息冗余：先辨明局部功能，再删除无用框架或重组句段；有效的回指、承接和解释准备继续表达，复述按局部用途保留、合并或补充已有内容。
- 语义指向：从材料中补明对象、动作、来源或变量关系，将失配比喻还原为字面表达；空泛评价词写成具体属性或删去，不换成另一个评价词，删后不留更泛的命题。
- 论证姿态：有归属的对立面保留并写明；没有归属的删去引子，直接写结论及条件，不改变作者确定度，不把真实边界或反例当作被否定的一半删掉。
- 文体组织：按内容关系调整正文结构；并列罗列写出关系或判断，各项有内容的保留；标题重新提炼所辖主题，保留检索把手，形式按用途选择，保留有用的平行结构。书面腔虚词按段落恢复主语和直接动词，不加口语填充。代码文档借词还原为本领域事实、正式条件和具体安排，删除伪程序权威，保留严格结论及其后果。

分词尾句、This design enables等句式可表达新的能力或结果含义，不一律删总结句。归因必须来自已有材料，不能通过换词补造原因；学术材料不足或结果与主张冲突时按academic-writing作者规则处理。原有可能性和条件保留，不按may等词自动加强结论。

每次修改都比较原文与修订文的受影响段落及必要上下文，核对回指对象、比较双方与单位、共同关系的位置、解释顺序和目标语言搭配，判断理解、精度或自然表达的具体改善。删后关系断裂时，恢复必要成分或依据材料重组；没有实质改善的改写无需采用。标题概括须保留原有的检索区别。

换词可以修复实际的搭配或指代问题；只减少命中而空泛功能仍在时继续修复。标题统一改成冒号或问句、只把“与”换成“和、及”、“不是 X 而是 Y”倒装、库存比喻互换、“清晰”换“明确”、执行名目改名，同样按其阅读作用判断。

输出修订后正文。用户要求对照或存在影响成稿的未解决事项时，补充必要说明。
```

## 修订复核 prompt

实际修改均需随改随读；需要单独比较原稿与改稿时使用本 prompt。

```text
比较 ORIGINAL 与 REVISED，围绕原问题检查表达功能、阅读关系及受保护内容。

先读受影响的连续句段：所指对象能否还原，承接是否完整，具体解释能否接上共同关系，比较成分和单位是否齐备，目标语言搭配是否自然。原问题消失但出现解释跳步、搭配失常或标题更空泛时，修订仍需恢复或重组。区分原稿已有问题与修订引入问题。

信息冗余：原有表演、复述或修饰是否失去冗余功能，是否只是换词或移到别处。
语义指向：对象、来源和关系是否更清楚，比喻是否仍缺少准确映射。
论证姿态：被否定的选项是否只是倒装或换成“与其说……不如说”，虚设对手是否只是换了说法而仍无归属。
文体组织：原有模板或跨域文风是否仍在；标题是否只把“与”换成“和、及、/”、冒号或整套问句；书面腔是否只在“尚未/仍未”“进行/开展”之间替换；语域借词是否只在“硬刹车/硬闸门”“盲区审计/风险扫描”“兜底/降级路径”之间替换。保留有用的一致性。

核对受修改影响的事实、数字、公式、引用、专名、必要限定和作者结论力度。只复核受影响内容，已有明确结果无需重复检查。

说明仍有问题、发生迁移或阅读退化的位置及依据；需要结构化比较时，对原问题使用 cleared / migrated / unresolved，阅读退化尚未修复时保持 unresolved。不评价作者身份或 AI 概率。

ORIGINAL:
[ORIGINAL]

REVISED:
[REVISED]
```
